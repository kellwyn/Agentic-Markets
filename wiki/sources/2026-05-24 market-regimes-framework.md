# Market Regimes — three-pillar framework

**Source:** mind map provided by user 2026-05-24, transcribed at
[[2026-05-24 mindmap market-regimes]].
**Origin:** unknown attribution; India-flavored framework for identifying
and navigating regime change.

## TL;DR
- Defines a regime by **time frame** (intraday → yearly) + **persistence**
  (sustained, not a one-off spike) + measurable parameters.
- Three pillars:
  1. **Macroeconomic** — rates, inflation, institutional flows (FII/DII),
     currency, commodities, structural shifts (QE, 1991 liberalization).
  2. **Structural / Regulatory** — taxation (LTCG, STT), operational
     changes (pre-open, T+1), leverage (peak margin), product evolution
     (weekly options), regulatory oversight (SEBI, ASM/GSM).
  3. **Micro / Market Structure** — technical indicators (200-DMA,
     distance from ATH), volatility (realized vs implied, India VIX),
     breadth, factor rotation (value/momentum/growth), market-cap rotation.
- Explicitly names three practical challenges: **hindsight bias**,
  **real-time uncertainty**, **navigation skills vs analysis**.

## Key takeaways
- **Regulation is treated as load-bearing**, not as a footnote. Most
  Western regime frameworks collapse into Pillar 3 (technicals + factors).
  This framework refuses to.
- **India-specific context** is concrete and dated:
  SEBI = the regulator; T+1 = settlement cycle; STT = securities
  transaction tax; ASM/GSM = surveillance frameworks; India VIX =
  volatility index; FII/DII = foreign / domestic institutional investors.
  Tag region: IN on derived pages.
- **Honesty about hindsight bias** is the most useful frame. A regime
  framework that reads clean ex-post is not the same as one that operates
  ex-ante. The framework's own author flagged this.
